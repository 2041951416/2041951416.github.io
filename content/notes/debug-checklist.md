板子焊好、程序烧进去，什么都没发生。这时候最忌讳的就是打开 IDE 改代码猜。**硬件问题按硬件查，软件问题按软件查，别混着来。**

下面是我现在固定走的顺序，每一步都能排除掉一大类原因。

## 第 0 步：别急着上电

焊接完先目视 + 万用表：

- 电源和地之间电阻不能是 0（短路）或无穷大（虚焊）
- 电解电容极性、二极管方向、芯片 1 脚方向
- 用放大镜看有没有连锡（尤其 0.5 mm 间距的 QFP）

**先串一个限流电源或用可调电源设 100 mA 限流**。这一步能救回很多板子。

## 第 1 步：电源

上电后第一件事，用万用表测每一个电源网络的电压：

| 检查点 | 期望 | 常见异常 |
|---|---|---|
| 输入 5V/12V | 标称 ±5% | 电源没接、保险丝断了 |
| LDO 输出 3.3V | 3.3 ±0.1V | 负载短路导致掉压、LDO 焊反 |
| MCU 的 VDD 各脚 | 3.3V | 某脚虚焊 |
| VDDA（模拟电源） | 3.3V | 漏焊、滤波电容不良 |

如果 3.3V 只有 1.2V 左右，八成是**某处短路**——用手摸（小心烫）或者红外测温找发热点，或者断开负载分段测。

## 第 2 步：时钟

电源正常但 MCU 不动，用示波器看晶振：

```c
// 没有示波器也可以间接判断：读时钟就绪标志
while (!(RCC->CR & RCC_CR_HSERDY)) {
    // 卡在这里 = 晶振没起振
}
```

晶振不起振的常见原因：

- 负载电容值不对（一般 8–22 pF，看晶振规格书）
- PCB 上晶振离 MCU 太远，走线太长
- 焊了但没焊好，或者用了错误的封装

**实在起不来可以先用内部 HSI 跑通，把问题隔离出来**，不要卡在晶振上耗一整天。

## 第 3 步：复位

`NRST` 引脚是不是一直被拉低？

- 用万用表测 `NRST` 电压，正常应该是高（约 3.3V）
- 如果接近 0V，看是不是复位电路电容焊错、或者外部复位信号没释放
- 检查 BOOT 引脚电平：BOOT0 拉高会进 bootloader，程序不跑

这一步花两分钟，能排除掉一类"程序好像根本没烧进去"的假象。

## 第 4 步：能不能连上调试器

这时候才打开 IDE，先**不烧程序**，只连接：

- 能连上 → 芯片活着，电源和时钟基本没问题，问题在程序
- 连不上 → 回到第 1–3 步，或者检查 SWD 的 SWDIO/SWCLK 是否接反、有没有被复用成普通 IO

如果之前烧过程序导致 SWD 被禁用，用 **connect under reset** 模式连接。

## 第 5 步：程序跑起来了吗

能用调试器之后：

1. 单步执行，看 PC 停在哪
2. 如果是 `HardFault_Handler`，看 `CFSR` 寄存器判断故障类型
3. 打个断点在 `main()` 第一行，看能不能进去

`HardFault` 最常见的三个原因：

- 访问了未使能时钟的外设寄存器
- 数组越界 / 空指针
- 栈溢出（中断里递归或大局部数组）

## 第 6 步：外设逐个点亮

程序能跑但外设不工作，就一个一个来：

```c
// 最小可验证单元：只点一个 GPIO
HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);
```

只配 GPIO，不配其他任何东西。确认能翻转，再往上加。**一次只加一个变量**，否则出问题不知道是谁造成的。

## 备查清单

上电后什么都不发生时，按这个顺序念一遍：

1. 电源对地短路？→ 测电阻
2. 电源电压正确？→ 万用表逐网络测
3. 晶振起振？→ 示波器 / 读就绪位
4. 复位释放？→ 测 NRST 电压
5. BOOT 引脚正确？→ 测电平
6. 调试器能连？→ connect under reset
7. 程序进了 HardFault？→ 读 CFSR
8. 外设时钟使能？→ 读 RCC 寄存器
9. 引脚复用配置对？→ 核对数据手册表格
10. 一次只改一个变量

**第 1–4 步是硬件，5–10 步是软件。** 大部分"玄学问题"都死在 1–3 步。养成从电源开始查的习惯，比任何调试技巧都管用。
