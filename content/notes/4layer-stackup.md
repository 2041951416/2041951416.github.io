第一次画板子时，我以为四层板只是"多两层放线"。真正画完一块之后才明白：**四层板买的是参考平面，不是布线面积。**

## 回流电流去哪了

任何信号都是有去有回的。电流从驱动端经走线到接收端，再**从地平面返回来**——而且它走的是"阻抗最小的路径"，在高频下就是**紧贴着信号线正下方**。

两层板的问题就在这里：

```text
两层板（坏的叠层）
┌────────────────────┐
│ 信号走线            │  ← Layer1
├────────────────────┤  FR4 ≈ 1.6mm
│ 信号走线 + 地铺铜   │  ← Layer2
└────────────────────┘
```

Layer1 的信号下面没有任何完整的地，回流电流只能绕远路，在板子上兜一个大圈。这个回路面积大，等效电感就大；电感大 → 边沿变缓 → EMI 变差，还可能形成天线把干扰辐射出去。

四层板把这个回路压缩到 0.2 mm：

```text
四层板（好）
┌────────────────────┐
│ L1  信号 / 元件      │  ← 顶层
├────────────────────┤  ≈ 0.2mm
│ L2  GND（完整地平面）│  ← 关键
├────────────────────┤  芯板
│ L3  电源平面        │
├────────────────────┤  ≈ 0.2mm
│ L4  信号            │  ← 底层
└────────────────────┘
```

L1 的信号，回流电流就在 L2 上正下方；L4 的信号，回流电流在 L3 上。回路面积 ≈ 信号到平面的距离 × 走线长度，小了两个数量级。

## 叠层顺序为什么是 S-G-P-S

最常见的四层顺序是 **信号–地–电源–信号**。理由：

1. 顶层信号有完整的地参考（最常用的一层，收益最大）
2. 底层信号离电源平面近，电源平面在高频下也是良好的交流地
3. 地和电源相邻，中间形成**板级平面电容**，虽然容值小（约 100 pF/inch²），但对高频有一定去耦作用

另一种顺序 **S-G-S-P** 也常见，特点是两层信号都能参考地，但底层信号离地远。如果底层几乎不放信号，S-G-P-S 更好。

**最差的是 S-S-G-P**——顶层信号下面紧挨着另一层信号，两层都在走线时互相串扰，等于没买平面。

## 平面被切开了怎么办

真正的麻烦不是“没有平面”，而是**平面被走线切开**。

想象一条信号从 L1 穿过 L2 的地平面，下面刚好有一条电源走线把地平面劈成两半。信号的回流电流不能跨越这条缝——它只能绕到很远的地方找个缝过，回路面积突然变大，EMI 立刻恶化。

**规则：不要在参考平面上开缝，尤其是信号正下方。**

如果无法避免，就在跨缝处的两侧放几个缝合电容（0.1 µF），给回流电流一条 AC 通路。

## 实际画的顺序

我现在画板的顺序是：

1. **先定叠层** — 板厚、层数、每层用途，算好阻抗目标
2. **先布关键信号** — 时钟、差分、高速总线，保证有参考平面
3. **再铺电源** — 按电流大小算线宽，或直接做电源平面
4. **最后铺地** — 铺铜要连通，避免出现"孤岛"
5. **DRC 之后回头看平面** — 切换 3D 视图或看每层铜皮，确认地平面没被切碎

## 一个心算标准

判断一块板画得好不好，我会看这几个数：

- 信号到参考平面的距离：**≤ 0.2 mm**（标准 4 层板芯板）
- 所有信号的参考平面：**完整、连续、无开缝**
- 地平面上的过孔：**够密**（缝合过孔间距 < λ/20，100 MHz 下约 15 cm，通常 1–2 cm 就够）

四层板比两层贵不了多少（打样可能就差十几块），但因为参考平面带来的信号质量提升是**数量级**的。只要板子上有超过 10 MHz 的信号，四层就是性价比最高的选择。
