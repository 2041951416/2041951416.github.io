云同步设置

开启后，勾选记录会存到你私人 Gist，多台设备自动合并。不开启也能正常使用， 数据只存在当前浏览器。

  1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Generate new token (classic)，只勾选 gist 这一个 scope
  3. 把生成的 token 粘贴到下面，点保存。首次保存会自动创建私有 Gist。

⚠️ 不能用 fine-grained token —— GitHub 的细粒度 token 不支持 Gist。 token 存在本机 localStorage，只给 gist scope，动不了你的代码仓库。

这份路线是怎么来的

不是抄的课程大纲。按「先能点亮一个 LED，再能画出第一块板」的顺序排的， 每一步都对应一件能独立验证的事。

任务是写在 content/plan.json 里的。想加、想删、想调整顺序直接改那个文件。 已经勾选过的任务不要改 id，否则进度会对不上。
