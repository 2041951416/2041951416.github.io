登录后才能编辑

这里没有账号密码。编辑权限由你自己生成的 GitHub 凭证决定， 只有持有它的人才能改动这个站点。

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate new token，Repository access 选 Only select repositories，只勾选 2041951416.github.io
  3. Repository permissions → Contents: Read and write，其余全部保持 No access
  4. 有效期建议不超过 90 天
  5. 复制生成的 token（github_pat_ 开头），粘贴到下面

⚠️ 这个 token 等于本站的写入权限。只在自己的设备上使用， 不要粘贴到聊天、帖子或录屏里。它不能访问你的其它仓库， 也不能改动部署配置。
